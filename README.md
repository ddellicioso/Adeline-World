## 🏁 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/yourusername/portfolio-sem-3.git
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the dev server
```bash
npm run dev
```
Open <http://localhost:3000> in your browser to explore.

---

## 📦 Building for Production
```bash
npm run build
```
Your optimized files will end up in the `dist/` folder, ready to be deployed.
